# Hi, I'm noodlequest! 👋

Small tools, sharp edges, no drama.

I spend most of my time writing Python that cleans, reshapes, and moves data from one place to another — ETL pipelines, exploratory notebooks, the kind of work that lives between a CSV someone emailed you and an insight someone actually trusts. Pandas and SQL are my daily drivers, though lately I've been pulling DuckDB into everything just to see how far it can go. I like the part of analytics where you're still asking questions, not yet selling answers.

#### Quick intro

- 🔭 Building a lightweight DuckDB pipeline to replace a tangle of old SQL scripts.
- happier in a terminal than in an IDE
- learning SQL the slow way
